Payment gateways

Elementor

8 widgets:

  • Add to Cart
  • Cart
  • Checkout
  • Currency Switcher
  • Product Grid
  • Product Price
  • Recommendations
  • Reviews

Block editor and shortcodes

7 blocks: Products, Buy Button, Cart, Checkout, Recommendations, Reviews and Currency Switcher. Each is also available as a shortcode, for example [wopcart_checkout].

Zapier

Triggers:

  • Order completed
  • Order refunded
  • New customer
  • Subscription started
  • Subscription canceled
  • New review
  • Cart abandoned

Webhooks

Send event payloads to any URL. Each delivery is signed with an HMAC over a timestamp and the body, so your endpoint can verify it came from your store.

  • Order completed
  • Order refunded
  • Invoice issued
  • Credit note issued
  • Subscription renewed

REST API

A REST API for your store, authenticated with API keys. Keys are stored hashed and shown only once, when you create them.

WP-CLI

  • wp wopcart status
  • wp wopcart orders
  • wp wopcart subscriptions
  • wp wopcart licenses
  • wp wopcart license-extend
  • wp wopcart rates
  • wp wopcart cron
  • wp wopcart install

Run wp help wopcart for the options of each command.

SEO plugins

WopCart detects Yoast SEO, Rank Math and All in One SEO and works with each of them:

  • Adds Product and paywall markup to the SEO plugin's own schema graph
  • Stops generated descriptions from exposing restricted text
  • Sets checkout, confirmation and account pages to noindex and removes them from the plugin's sitemap

Invoicing and AI

  • InvoicesGenerator: optional connector that receives each invoice for hosted PDFs and bookkeeping, while WopCart keeps the numbering
  • Anthropic Claude API: optional product recommendations, off until you add an API key

For theme and plugin developers

  • Override any template by copying it to yourtheme/wopcart/
  • Restyle the storefront with --wopcart-* CSS custom properties
  • Ship the WopCart updater class with the plugins and themes you sell
